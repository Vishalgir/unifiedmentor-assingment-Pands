# Pandas Data Manipulation Assignment

This repository contains a Jupyter Notebook (`.ipynb`) that covers essential data manipulation tasks using the **Pandas** and **NumPy** libraries in Python.

## 🛠️ Features & Tasks Covered

### 1. Pandas Series
* Creating Series and custom indexing.
* Sorting values and indices.
* Appending multiple Series objects.

### 2. Pandas DataFrames
* Converting Series into structured DataFrames.
* Renaming columns and analyzing data shapes.
* Merging and Concatenating datasets (e.g., merging city temperature data).

### 3. Data Transformation
* **Filtering:** Selecting data based on conditional logic (e.g., temperatures above 90°F).
* **Custom Functions:** Using `.apply()` for:
    * Categorizing cities into Union Territories.
    * Converting Celsius to Fahrenheit.

### 4. Advanced Grouping
* Using `.groupby()` to aggregate data.
* Performing multiple aggregations like `min()`, `max()`, `mean()`, and `sum()` on grouped data.

### 5. Time Series Analysis
* Generating date ranges with `pd.date_range`.
* Analyzing `DatetimeIndex` properties.

## 💻 Technologies Used
* **Python 3**
* **Pandas**
* **NumPy**
* **Jupyter Notebook**
